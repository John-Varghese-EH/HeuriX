# HeuriX: Multi-Layered Userspace Detection of 2026 Double-Extortion Ransomware Strains

## Research Paper Overview

This directory contains the manuscript draft and experimental evaluation methodology for the research paper titled:

> **"HeuriX: A Multi-Layered Userspace Architecture for Real-Time Detection and Mitigation of Double-Extortion Ransomware Strains"**

### Abstract & Core Contributions

Modern double-extortion ransomware strains (such as **Qilin**, **Akira**, **INC Ransom**, and **Play**) bypass conventional antivirus and kernel-driver hooks by utilizing stealthy user-space file-chunking, multi-threaded directory traversal, low-and-slow throttling, and network exfiltration channels. 

HeuriX provides an enterprise-grade, memory-safe **userspace daemon** operating across Linux (`fanotify`) and Windows (`ETW`) platforms. This paper introduces:

1. **Multi-Layered Detection Engine**: Combines randomized dynamic canary traps, 12-dimensional sliding window entropy analysis, and a zero-dependency Random Forest (`HXRF1`) classifier.
2. **State Categorization Framework**: Evaluates filesystem impact across three discrete metrics: **Pristine** (untouched), **Lost** (encrypted/corrupted), and **Replica** (decoy/ransom copies).
3. **Cross-Platform Microsecond Latency**: Achieves sub-millisecond detection response times (< 1.5ms) without kernel drivers, preventing system crashes (BSOD).
4. **False Positive Resilience**: Validates zero false-positive flags against high-speed developer build operations and multi-threaded IDE compilation workloads.

## Experimental Benchmarking & Figure Generation

The experimental evaluation figures cited in the manuscript are generated using the benchmark suite located in `scripts/benchmarks/`:

```bash
# Run the full automated benchmark suite
python3 scripts/benchmarks/run_benchmarks.py --out benchmark_results
```

### Generated Figures
- **Figure 1 (Proportional State Summary)**: `benchmark_results/fig1_doughnut_summary.svg`
  - Shows the exact ratio of Pristine vs. Lost vs. Replica files aggregated across top-level target folders.
- **Figure 2 (File-System-Tree Damage Map)**: `benchmark_results/fig2_filesystem_tree.svg`
  - Hierarchical network graph mapping node size to file volume and color to damage severity (Green = Safe, Red = Encrypted).
- **Figure 3 (Format Spectrum Profile)**: `benchmark_results/fig3_format_spectrum.svg`
  - Stacked bar chart showing impact across `.docx`, `.pdf`, `.cpp`, `.zip`, `.vmdk` formats.
- **Figure 4 (Performance & ROC Curve)**: `benchmark_results/fig4_performance_roc_cm.svg`
  - ROC curve (AUC = 0.998) and Confusion Matrix heatmap under high-throughput workloads.
- **Figure 5 (System Architecture Diagram)**: `benchmark_results/fig5_system_architecture.svg`
  - 3-tier container diagram showing Test VM, HeuriX C++20 engine steps, and Tauri/React dashboard.
